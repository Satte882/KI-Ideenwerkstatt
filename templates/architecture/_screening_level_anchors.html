Skalenanker Niedrig · Mittel · Hoch
  • {% if scope == 'stage' %}Impact{% else %}Strategischer Impact{% endif %}: Niedrig = lokal/indirekt · Mittel = relevanter Bereichs- oder Stakeholder-Beitrag · Hoch = unmittelbarer Einfluss auf zentrale Ziele, Stakeholder oder kritischen Betrieb.
    • {% if scope == 'value_stream' %}
  • Wirtschaftliches Potenzial: Niedrig = kleiner oder unsicherer Hebel · Mittel = relevanter, nachvollziehbarer Hebel · Hoch = wesentlicher Hebel auf Kosten, Erlös, Kapazität oder Risiko.
    • {% endif %}
  • Problemintensität: Niedrig = selten/lokal mit geringen Folgen · Mittel = wiederkehrend mit spürbaren Folgen · Hoch = häufig oder kritisch mit starken Qualitäts-, Zeit-, Kosten- oder Risikofolgen.
  • {% if scope == 'stage' %}Datenlage{% else %}Datenzugänglichkeit{% endif %}: Niedrig = fehlend/schwer zugänglich oder kaum nutzbar · Mittel = teilweise verfügbar, Klärung/Aufbereitung nötig · Hoch = relevante Daten sind zugänglich und ausreichend nutzbar.
  • Veränderungsaufwand: Niedrig = begrenzte Anpassung weniger Rollen/Systeme · Mittel = mehrere Beteiligte oder Integrationen mit planbarem Aufwand · Hoch = erhebliche organisatorische/technische Änderung oder starke Abhängigkeiten.
„Hoch“ ist nicht pauschal positiv: Bei Impact oder Datenlage beschreibt es eine starke Ausgangslage, beim Veränderungsaufwand einen hohen Aufwand.
