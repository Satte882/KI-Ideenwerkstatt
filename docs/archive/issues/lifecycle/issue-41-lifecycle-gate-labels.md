# Issue #41 – Lifecycle-Gate-Bezeichnungen

Die Use-Case-Seite leitet Überschrift und Blockertext aus dem aktuell geprüften `decision_check` ab.

Damit bleiben die Begriffe nach einer finalen Freigabe fachlich getrennt:

- `Pilot starten` für den Übergang von Prüfung zu Pilot,
- `Produktiv setzen` für den Übergang von Pilot zu Betrieb,
- `Betrieb fortführen` für die laufende Betriebsprüfung,
- `Abgeschlossen` für den beendeten Lifecycle.

Die Bezeichnung `Freigabe blockiert` bleibt ausschließlich dem eigentlichen Freigabe-Gate vorbehalten.
