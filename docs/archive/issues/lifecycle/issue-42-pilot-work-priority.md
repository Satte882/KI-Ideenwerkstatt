# Issue #42 – Pilotarbeit vor Go-live-Gate priorisieren

Ab dem tatsächlichen Pilotstart nutzt die Use-Case-Detailseite die bestehende Outcome-Journey.

Die verbindliche Reihenfolge lautet:

1. laufenden Pilot beobachten,
2. Wirkungsmessung vollständig dokumentieren,
3. Ergebnisentscheidung treffen,
4. erst danach über die Produktivsetzung entscheiden.

Solange Pilot oder Messung die aktuelle Arbeitsphase bilden, werden offene Go-live-Punkte nur als spätere Voraussetzungen dargestellt. Sie erzeugen auf der Detailseite keinen aktuellen roten Fehlerzustand und keine primäre Reparaturaktion.
