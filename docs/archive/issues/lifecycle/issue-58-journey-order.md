# Geführte Journey von Discovery bis Delivery

Die verbindliche Reihenfolge des systematischen Pfads lautet:

1. Value Stream strukturieren
2. Fokus und Priorisierung entscheiden
3. Fokusprozess analysieren
4. Lösungsoptionen dokumentieren und eine Option bevorzugen
5. Use Case ableiten und Intake vervollständigen
6. Strukturierte Bewertung erstellen
7. Governance-Screening und erforderliche Fachprüfungen abschließen
8. Verbindliche Freigabeentscheidung treffen
9. Delivery Package erstellen und übergeben

Ein nachgelagerter Schritt wird nur dann zur primären Next Action, wenn die Pflichtvoraussetzungen der vorherigen Schritte erfüllt sind. Direkte Ableitungen bleiben ausdrücklich als methodische Abkürzung gekennzeichnet.
